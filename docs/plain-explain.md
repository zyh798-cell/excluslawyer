# 大白话解释层（通俗模式）

> 状态：**已落地（普通人友好层 P0 第二项）** ｜ 范围：前端模板化解释 + 术语释义 ｜ 后端零改动
> 上游：[场景化入口](scenario-entry.md)（P0 第一项） ｜ 关联：KI-10（剩余 WIP 项）

## 1. 这一层解决什么问题

场景化入口解决了「怎么问」，但结果出来仍是专业表述：法言法语 + 条文编号，普通用户看完
还是不知道"这对我意味着什么"。

大白话解释层在**不改变任何结论**的前提下加一层翻译：

- 先看到一句话人话结论（"对你这件事意味着什么"）；
- 再展开看法条原文与专业分析（可折叠，原样保留）；
- 专业术语点开即得通俗释义 + 类比；
- 风险、证据不足、时效过期等提示**原样保留**，不因通俗模式省略。

## 2. 红线（设计与实现共同守住）

| 红线 | 实现方式 |
|---|---|
| 白话不得新增未检索到的法律依据 | `buildPlainExplanation()` 为**确定性模板**，输入只有后端返回的 answer / citations / NLI / 风险字段，无任何 LLM 调用 |
| 白话不得替代、改写或弱化法条原文 | 白话区只做「依据构成 / 程序提示 / 可信度」的结构性说明；法条原文完整收进可折叠区并列展示 |
| 风险与限制保持原样呈现 | 证据不足 / 时效过期 / NLI 降级 / 高风险的**原文句子直接复制**进警告区，不转写；另加自证声明"白话不改变任何结论" |
| 术语释义不提供结论 | `terms.ts` 每条释义只有概念解释 + 类比，测试断言不含"你应该 / 建议你 / 赶紧"等指令句式 |

## 3. 通俗模式开关

- 组件：`PlainToggle`（`role="switch"` + `aria-checked`，热区 ≥44px）
- 状态：`lib/plain-mode.ts` 模块级 store（`useSyncExternalStore`），**全站单例**
- 持久化：`localStorage["excluslawyer.plain"]`（`"plain"` / `"pro"`），默认 `plain`
- 一致性：对话页（快速咨询 / 状态机）、意见书、KG 面板、模拟法庭裁决卡共用同一状态，
  任何一处切换全站即时同步

## 4. 白话生成规则（`lib/plain-explain.ts`）

输入信号 → 确定性模板输出：

```
headline（一句话：对你意味着什么）
  优先级：证据不足 > 时效过期 > 裁决结论（全支持/全驳回/混合） > NLI 降级 > 置信度分档 > 默认导览

reasons（2–4 句）
  ① 依据构成：引用的 N 条法条（只列 law_title + article_no，来自 citations，绝不新增）
  ② 程序提示：仅当原文提到仲裁前置/仲裁/诉讼/投诉时，提示"原文中提到了什么"（不做行动指引）
  ③ 可信度：confidence + NLI 状态直译
  ④ 时效提醒：原文涉及时效且未过期时提示"别拖"

warnings（原样保留，不转写）
  ① 后端 risk_notes 原文行
  ② 主文中的标记句原样（证据不足/时效届满/降级…）
  ③ NLI 降级：后端 reason 原文 + 一致性百分比
  ④ 风险等级直译（high/medium）
  ⑤ 自证声明："白话只是说明，不改变任何结论"
```

## 5. 展示分区（`PlainAnswerCard` / `PlainAnswerSection`）

通俗模式开：

```
┌ 大白话结论区（neu-inset，术语带下划虚线可点击）
├ 风险与限制区（warn 色块，显性展示、不折叠）
└ 法条原文与专业分析（<details> 可折叠，专业内容原样放入）
```

通俗模式关：直接渲染专业视图（现有展示，零改动）。

接入点：

| 结果区 | 专业内容（折叠区） | 风险输入 |
|---|---|---|
| 快速咨询（/api/ask） | answer + 引用法条一览 | NLI / 置信度 |
| 状态机深度咨询 | answer + 执行轨迹 | NLI / 降级出稿说明 |
| 法律意见书（OpinionView） | 五段式全文 + 风险理由 | risk_level / risk_reasons |
| 模拟裁判（VerdictCard） | 逐条明细 / 类案 / 跨法域 | risk_notes / 逐条 decision |

## 6. 术语即时释义（`terms.ts` + `TermHint`）

- 26 个高频术语：诉讼时效、除斥期间、举证责任（含倒置）、不可抗力、缔约过失、违约责任、
  请求权基础、连带责任、诉讼保全、仲裁前置、管辖、定金、押金、经济补偿、赔偿金、二倍工资、
  违约金、合同解除、瑕疵担保、欺诈、重大误解、拘留、诉讼、仲裁、调解 等
- 每条 = 标准名 + 别名 + 一句话通俗释义 + 一句类比（如 诉讼时效 ↔ "像食品保质期"）
- 匹配策略：长词优先（「仲裁前置」不被「仲裁」吃掉），位置推进扫描
- 展示：点击术语在原位下方展开释义卡（内联展开式，无绝对定位，窄屏零溢出）；
  `aria-expanded` / `aria-controls` / `role="note"`

## 10. 免责声明

本层不改变任何法律输出内容的性质。所有结论仍须挂现行有效法条原文、检索不到就说「证据不足」、
保留双视角对抗与时效标注；白话解释区与专业区并列展示，用户随时可切回专业模式核对原文。
