# 普通人友好层 · 场景化入口（P0）

> 状态：**已落地（P0）** ｜ 范围：前端采集骨架 + 场景配置 ｜ 后端零改动
> 关联：KI-09（多语言 UI 未实现）、KI-10（本层后续功能 WIP）、KI-11（问卷服务端校验未做）

## 1. 这一层解决什么问题

传统法律引擎的入口是「一个搜索框 + 一个法域下拉」，要求用户先知道自己的问题属于什么法律关系、
该查哪部法。普通人做不到，于是「能检索」并不等于「能问对」。

场景化入口把第一步替用户走完：**选一个生活场景 → 按提示填几步 → 自动整理成结构化案情摘要 → 预填进提问框 → 用户确认或修改后再发送**。

底层能力一点没变：检索、法条核验、双视角对抗、模拟法庭全部复用既有实现。**本层只是把「怎么问」这件事前置，答案的出具标准仍然是四大铁律。**

## 2. 八个生活场景

配置文件：`frontend/src/config/scenarios.ts`（新增场景只需追加一条，无需改组件）

| 场景 | 一句话适用说明 | 典型问题标签 | 关联法域 |
|---|---|---|---|
| 租房与押金 | 押金被扣、押金拿不回、没签合同、房东提前解约 | 押金被扣 / 押金不退 / 没签合同 | CN |
| 劳动与离职 | 拖欠工资、未签合同二倍工资、加班费、被违法辞退 | 拖欠工资 / 二倍工资 / 违法解除 | CN |
| 消费维权 | 退款难、货不对板、预付卡跑路、价格欺诈 | 退款 / 货不对板 / 预付卡 | CN |
| 婚姻家庭 | 离婚财产分割、抚养权、彩礼、共同债务 | 离婚分割 / 抚养权 / 彩礼 | CN |
| 交通事故与人身损害 | 责任认定、赔偿范围、误工费与工伤认定 | 责任认定 / 赔偿范围 / 误工费 | CN |
| 小额借贷与合同纠纷 | 欠款不还、借条缺失、对方失联、催收无果 | 欠款不还 / 借条 / 催收 | CN |
| 留学签证与学业事务 | 签证被拒、居留续签、学费纠纷、学历认证 | 签证被拒 / 居留续签 / 学费纠纷 | CN / JP / KR / SG |
| 其他 / 直接提问 | 不属于以上场景，或你想直接描述问题 | 其他问题 / 直接提问 | CN / JP / KR / SG |

每个场景定义：

```ts
interface Scenario {
  id: ScenarioId;               // 稳定标识
  name: string;                 // 场景名
  summary: string;              // 一句话适用说明
  tags: string[];               // 2–4 个典型问题标签
  jurisdictions: JurisdictionCode[];  // 关联法域标签
  icon: ScenarioIconName;       // 统一内联 SVG 图标名
  fields: ScenarioField[];      // 问卷字段（按顺序分步展示）
  askPrompt: string;            // 生成摘要时的诉求提示句
}
```

## 3. 交互流程

```
首页顶部  ┌─ 产品标识（内联 SVG 天平徽记 + 定位文案）
          └─ 法域选择器（radiogroup，与咨询卡 select 双向同步）
                 │
     生活场景栅格 ├─ 8 张卡片（手机 1 列 / 平板 2 列 / 桌面 3 列 / 超宽 4 列）
                 │   每张卡：图标 + 名称 + 适用说明 + 问题标签 + 法域徽章
                 │
                 ▼
          分步问卷 ├─ 一次一个问题，顶部进度条 + 「第 N / M 步」
                 │   必填未填 → 下一步禁用并给出原因（不静默跳过）
                 │   底部：上一步 / 下一步；底部回显「已填写要点」
                 ▼
          结构化摘要 ├─【场景】标签：值；标签：值。…… + 该场景的诉求提示句
                 │   未填写的可选字段自动跳过，不产生空值噪声
                 ▼
          提问框预填 ├─ 摘要写入提问框，用户可自由编辑后再发送
                 │   走既有 /api/ask 流程（不新增后端问卷逻辑）
```

### 法域联动

- 顶部法域选择器与咨询卡内的 `选择法域` select 是**同一份状态**，双向同步。
- 场景关联法域与当前法域不一致时，卡片上会标注「（选它将自动切换法域）」；
  点击该场景时自动切到它关联的第一个法域 —— 普通人不需要预先理解法域差异。
- 「留学签证与学业事务」覆盖四法域，其余场景当前均为 CN。

### 保留原有路径

自由提问入口完全保留（`aria-label="法律问题描述"` 的提问框），场景入口是**增量**而非替换；
顶部模式切换（法律咨询 / 合同风险扫描 / 类案参考 / 模拟法庭 / 工具箱）不受影响。

## 4. 视觉与可访问性规范

| 项 | 实现 |
|---|---|
| 玻璃拟态 | 场景卡 / 问卷卡沿用 `.card`（`--glass-*` 变量 + backdrop-filter + 不支持时降级实体卡） |
| 新拟态 | 图标底座用 `.neu-inset`，按钮沿用 `.btn` / `.btn-primary` / `.btn-ghost` |
| 颜色 | 全部走全局 CSS 变量，亮暗主题同步切换（`html.dark`） |
| 图标 | 统一内联 SVG（`ScenarioIcon` / `BrandMark` / `WarningIcon`），**不使用 emoji** |
| 骨架屏 | 摘要整理过程显示骨架占位（`.skeleton`），避免预填跳变 |
| 动效降级 | `prefers-reduced-motion: reduce` 时全局关闭动画（`globals.css`） |
| 窄屏优先 | 375px 单列不溢出；栅格 `grid-cols-1 / sm:2 / xl:3 / 2xl:4` |
| 热区 | 可点击元素 ≥ 44×44px（卡片整块可点，按钮 `min-h-[44px]`） |
| 语义 | `ul/li` 列表 + 整卡按钮；`radiogroup` 法域选择；`progressbar` 问卷进度；必填错误 `role="alert"` |

### 本轮修复的可访问性问题（Lighthouse 12.8.2 实测）

| 问题 | 现象 | 修复 |
|---|---|---|
| BYOK 面板对比度 | 折叠标题用 `text-fg-subtle`，12px 对白底不足 4.5:1 | 浅色主题 `--c-fg-subtle` 由 `120 135 158` 调深至 `88 100 119`；暗色由 `100 116 139` 调亮至 `118 132 152` |
| 法域徽章对比度 | 浅色主题法域色过浅，徽章文字不达标 | 浅色主题四个法域色各降一档（CN `220 38 38`→`178 34 34` 等）；暗色不变 |
| 场景卡片可访问名 | `aria-label="选择场景：X"` 与可见文案不匹配（label-content-name-mismatch） | 去掉 `aria-label`，可访问名直接取自可见文本；改用 `ul/li` 语义列表 |
| 角色误用 | `<button role="listitem">` 属不兼容角色 | 改为真实 `ul > li > button` |
| BYOK 标题标签 | `aria-label` 覆盖了可见文案 | 改用 `sr-only` 前缀补充动作说明，可访问名包含全部可见文本 |
