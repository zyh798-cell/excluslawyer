## 安全隐患

| 级别 | 项 | 说明 | 规避方案 |
|---|---|---|---|
| 🟡 | BYOK 模式下 LLM 供应商 CORS | 部分供应商不允许浏览器跨域直连（如部分 Claude 网关），届时 BYOK 流程会失败 | 已在 UI 提示；后续可加本地代理模式（localhost proxy），Key 仍不出用户机器 |
| 🟡 | localStorage 明文存 Key | 同机其他脚本/扩展可读取（XSS 场景） | 已有注入检测+错误打码+载荷守卫三道防线；后续可选 Web Crypto 口令加密存储（需用户设主口令） |
| 🟢 | `NEXT_PUBLIC_API_BASE` 可被构建时替换 | 非密钥（后端地址），但若指向恶意后端，检索结果可被投毒 | 部署文档注明仅信任自建后端；后续可加响应签名校验 |
| 🟢 | 错误上报链路 | 目前错误只进 Toast/页面，不上报远端（隐私友好） | 保持默认不上报；若未来加遥测必须脱敏+用户 opt-in |

| 级别 | 项 | 说明 | 规避方案 |
|---|---|---|---|
| 🟡 | G6 画布大图性能 | 节点 >200 时 Canvas2D 节流/聚合需加强 | 当前子图规模小（多跳 ≤2 跳）；后续加 LOD/缩放聚合 |
| 🟡 | 演示模式长答案 DOM | 超长法条摘录全量渲染（whitespace-pre-wrap） | 后续虚拟滚动或折叠长文本（判例区已折叠） |
| 🟢 | backdrop-filter 合成开销 | 低配设备多卡片模糊有 GPU 开销 | 已有 `@supports` 降级；后续可加低性能设备整体降级开关 |
