## 优化措施归因

1. **代码分割**：路由级 Next 自动分割 + G6 画布 `import()` 懒加载（不入首包）
2. **零 Web 字体**：system-ui 字体栈，无字体下载阻塞、无字体 CLS
3. **主题防闪烁**：layout 内联主题脚本（首帧前定类）→ CLS = 0 的关键
4. **骨架屏**：加载态占位固定高度，避免内容跳动
5. **静态预渲染**：全路由 ○ Static，服务端响应 10ms
6. **聊天/咨询页零 WebGL/Canvas 负载**：G6 仅工具箱 KG 面板按需加载（规范要求满足）
